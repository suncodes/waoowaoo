# AI 视频创作工作台交互重构方案 V3

- 状态：方案确认并进入实施
- 日期：2026-07-20
- 实施范围：现有工程内重构，不新建独立工程
- 目标用户：不熟悉模型、提示词和专业视频流程的内容创作者

## 1. 重构目标

当前新版工作台已经完成六阶段外壳，但内部仍复用旧页面，导致阶段名称、页面内容和后台任务之间没有形成清晰关系。本轮重构以用户成果为中心，不再以接口或任务名称组织界面。

产品目标：

1. 用户始终知道当前正在做什么、为什么需要确认、下一步是什么。
2. 后台任务开始执行时，页面自动跟随到对应阶段，不让用户误认为卡住。
3. 内容、画面需求、视觉资产和分镜之间边界清晰。
4. 关键成果可以编辑、保存、确认和重新生成。
5. 后端能力不足时保留完整产品契约，通过适配层逐步补齐，不反向压缩交互设计。

## 2. 产品流程

用户可见流程统一为：

```text
创作设定 -> 内容创作 -> 画面准备 -> 分镜预演 -> 镜头制作 -> 剪辑成片
```

内部按视频制作阶段分组，但不强迫普通用户理解专业术语：

```text
前期准备：创作设定、内容创作、画面准备
制作阶段：分镜预演、镜头制作
后期阶段：剪辑成片
```

## 3. 阶段定义

### 3.1 创作设定

用户输入创作材料并确定视频类型、画面比例、风格、制作方式和画面检查策略。

页面采用普通表单分区，不使用多个大型卡片：

```text
作品类型
创作材料
视频规格
创作偏好
画面检查
```

“图片质量辅助”改为“画面检查”，使用紧凑分段控件：

```text
画面检查    [仅提醒 | 自动修复]
            生成后自动检查异常画面，发现问题时按所选方式处理
```

模型名称、评分阈值和内部重试策略进入高级设置，不在主流程展示。

### 3.2 内容创作

内容创作不是单一剧本页，而是包含内容结构、可编辑文稿和画面需求。

书籍导读：

```text
内容结构 | 解说文稿 | 画面需求
```

AI 漫剧：

```text
故事结构 | 分场剧本 | 角色与场景
```

内容结构用于确认叙事目标、顺序和重点。解说文稿或分场剧本必须支持直接编辑和自动保存。

画面需求只描述需要什么，不在此阶段确定最终图片：

- 角色、道具、场景分类。
- 名称和描述可编辑。
- 标记是否需要保持一致。
- 展示是否已有参考图或定稿图。
- 支持重新识别画面需求。
- 支持进入画面准备继续制作。

### 3.3 画面准备

画面准备负责把文本需求转化为可复用视觉资产：

```text
整体风格 | 核心形象 | 场景画面 | 待处理问题
```

主要操作：

- 查看和调整整体视觉方向。
- 生成角色、重要道具和场景候选图。
- 选择最终形象、重新生成、上传替换和编辑描述。
- 展示一致性检查和生成问题。
- 核心资产确认后进入分镜预演。

核心重复资产需要确认；普通一次性背景允许自动通过。

### 3.4 分镜预演

以镜头顺序展示画面、旁白、时长和运动意图。支持局部修改、重新生成和确认进入镜头制作。

### 3.5 镜头制作

统一管理画面生成、视频生成和配音。默认按镜头显示完成、生成中、待确认和失败状态，不把视频和配音拆成两个顶层阶段。

### 3.6 剪辑成片

提供时间线、字幕、配音、音乐、转场和导出。当前已有合并导出能力通过适配层接入，后续再补完整编辑器能力。

## 4. 自动跟随和阶段推进

自动跳转分为两类：

### 4.1 任务跟随

后台任务开始时，页面自动进入任务所属阶段和子视图：

| 后台任务 | 页面位置 |
|---|---|
| 内容规划 | 内容创作 / 内容结构 |
| 生成剧本或解说 | 内容创作 / 文稿 |
| 视觉规划 | 画面准备 / 整体风格 |
| 生成分镜 | 分镜预演 |

仅在用户位于当前阶段或更早阶段时自动跟随。用户主动查看后续阶段时，不强制拉回。

### 4.2 成果推进

阶段完成并且没有阻塞问题时，展示三秒倒计时：

```text
当前阶段已完成，3 秒后进入下一阶段    [留在此处]
```

以下情况禁止自动推进：

- 有未保存修改。
- 有失败或需要人工确认的问题。
- 用户已经主动切换页面。
- 下游结果会被覆盖且尚未确认。

首轮实现优先完成任务跟随。成果自动确认和倒计时推进需要后端提供正式的成果确认状态后再启用。

## 5. 工作台布局

桌面端采用稳定三栏：

```text
左侧：六阶段流程、状态和问题数
中间：当前阶段可编辑成果
右侧：当前状态、问题和生成详情
底部：保存、重新生成、确认并继续
```

在中等屏幕和移动端，右侧面板收为“制作助手”抽屉。阶段导航变为可横向滚动的步骤条。

页面主区域只展示用户成果。模型思考、任务步骤和重试信息统一放入“生成详情”，默认折叠。

## 6. 成果状态模型

所有阶段成果统一使用以下状态：

```text
未开始 | 生成中 | 待确认 | 已确认 | 需要更新 | 失败
```

后续后端需要补充：

- 草稿和确认状态。
- 成果版本号。
- 下游依赖和失效范围。
- 用户修改与模型生成内容的归属。

当前阶段状态先由已有数据和任务状态映射，避免修改数据库。

## 7. 资产交互边界

内容创作阶段展示“画面需求”，允许编辑名称和描述，但不直接生成最终图片。

画面准备阶段展示“视觉资产”，负责候选图生成、选择和确认。

```text
文稿识别画面需求
-> 用户修正需求
-> 确定整体风格
-> 生成候选图
-> 自动检查
-> 确认核心资产
-> 生成分镜
```

已有资产 API、图片生成和选择能力继续复用，但通过新页面组织，不直接复用旧的整页布局。

## 8. 工程结构

不新建独立工程。当前工程已经包含用户、项目、任务、计费、模型配置、存储和国际化，新建工程会产生双重状态和重复能力。

在当前工程建立独立边界：

```text
src/lib/creation-workspace/                 阶段、状态和路由契约
components/workspace-v2/                    工作台外壳和通用交互
components/workspace-v2/stages/             六阶段页面
components/workspace-v2/artifacts/          文稿、画面需求、视觉资产等成果组件
components/workspace-v2/adapters/           旧数据和旧 API 适配
```

允许复用：

- 文本编辑器。
- 图片候选选择器。
- 上传器、播放器和时间线。
- 任务流和查询 Hook。

不再复用：

- 旧版完整阶段页面。
- 将脚本、资产和生成按钮混在一起的旧布局。
- 直接暴露后台任务名称的 TAB 和导航。

## 9. 实施顺序

### UI-1：阶段与任务跟随

- 更新阶段命名。
- 实现后台任务驱动的页面自动跟随。
- 保留用户主动导航优先级。

### UI-2：创作设定

- 压缩画面检查区域。
- 重排视频类型、输入和规格设置。
- 删除重复说明卡片。

### UI-3：内容创作

- 增加三类子视图。
- 分离文稿编辑和画面需求。
- 书籍导读提供解说文稿编辑。
- 画面需求支持实际资产数据的展示和编辑。

### UI-4：画面准备

- 重组视觉方向与资产制作入口。
- 增加核心资产完成度和问题摘要。
- 保留旧资产能力作为底层详细编辑器。

### UI-5：确认状态和局部重生成

- 新增成果版本、确认、失效和影响范围后端能力。
- 接入完整的成果推进规则。

## 10. 首轮验收标准

1. 点击开始创作后，页面自动进入正在运行的阶段。
2. 画面检查不再使用两个大型说明卡片。
3. 内容创作根据视频类型显示不同文案。
4. 文稿和画面需求不再被塞在同一个旧版双栏页面。
5. 画面需求可查看、编辑并明确进入画面准备。
6. 画面生成和最终形象确认只出现在画面准备。
7. 桌面端和移动端无页面级横向溢出。
8. 正式页面不存在无效按钮或仅供演示的假数据。

## 11. 2026-07-20 实施结果

本轮已完成：

- 六阶段名称调整为“内容创作”和“画面准备”等用户语言。
- 新增任务自动跟随，内容规划、文稿、视觉规划和分镜任务开始时自动进入对应页面。
- 创作设定中的画面检查改为紧凑分段控件。
- 新版创作设定移除旧资产库说明卡片。
- 内容创作增加内容结构、文稿、画面需求三个视图。
- AI 漫剧文稿编辑与旧资产双栏页面分离。
- 书籍导读增加可编辑解说文稿，并复用现有内容计划保存能力。
- 画面需求读取当前项目资产，支持名称和描述编辑、状态展示与重新识别。
- 画面准备增加资产完成度摘要，并提供正式的分镜生成入口。
- 书籍导读不再在内容规划后直接跳过确认环节，而是在画面准备阶段明确启动画面方案与分镜。

本轮未实现：

- 成果级草稿、确认和版本状态。
- 修改后下游失效范围计算。
- 三秒倒计时式成果自动推进。
- 核心资产强制确认门禁。
- 书籍导读专用的结构化资产识别模型。

以上能力属于 UI-5 及后续后端契约，不在当前界面改造中伪造。
